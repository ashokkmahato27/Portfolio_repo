## 🎯 About The Project

This portfolio website showcases my skills, projects, and achievements as a Computer Science student passionate about AI, Machine Learning, and Cybersecurity. The website features a modern tech-themed design with a dark color scheme, neon accents, and interactive elements that create an engaging user experience.

### Why This Portfolio?

- ✅ **No frameworks required** - Pure HTML, CSS, and JavaScript
- ✅ **Fully responsive** - Works on all devices and screen sizes
- ✅ **Fast loading** - Optimized performance with minimal dependencies
- ✅ **Easy to customize** - Well-organized and commented code
- ✅ **SEO friendly** - Semantic HTML structure
- ✅ **Accessible** - Following web accessibility guidelines
